
# Project title

This project is titled: "Exploring associations between trust in doctors and the likelihood of accessing healthcare for anxiety, depression and menstrual problems". 


## Description

This study used data from the Avon Longitudinal Study of Parents and Children to investigate the associations between trust in doctors and healthcare access at two timepoints, for anxiety, depression (mothers and partners) and menstrual problems (mothers only). Data was taken from two timepoints, when the parents' index child was 21 months old and 6 years old.To account for missing data, regressions were run on the original, complete-case and multiple imputation datasets. 

## Scripts

In this repository, there are 2 separate folders for the different timepoints. Within each folder, there are 3 folders for each dataset:
- the original dataset
- the complete-case dataset 
- the multiple imputation dataset. 

Each of these folders has 5 folders:
1. Packages script
2. Import and clean script
3. Data descriptives script
4. Analysis and visualisation script
- Data 

These folders are to be run in order.
